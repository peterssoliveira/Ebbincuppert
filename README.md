# Ebbincuppert

Comecei o projeto para desenvolvimento de um sistema de estudos, utilizando diversas linguagens em conjunto como: Python, Html, CSS, tudo em Local Storage com SQL

iniciei listando a funcionalidade básica do projeto: Acompanhar a curva de aprendizagem de um determidado assunto/matéria, tudo baseado na teoria de Curva do Esquecimento e Retenção de Ebbinghaus.

Dentro das funcionalidades iniciais: fazer o lançamento de uma introdução de conteúdo (o tema/matéria que estudei, juntamente com a data dessa introdução) e o sistema colocaria para mim os proxímos dias das revisões de acordo com o método de Ebbighaus (1, 7, 30, 90, 180)

O projeto foi batizado como "EbbinCupert" em homenagem a duas inspiraçõs, o criador da teoria de Curva do Esquecimento e Retenção: Hermann Ebbinghaus e ao frade José de Cupertino, canonizado como Santo da Igreja Católica Apostólica Romana em 1767 pelo Papa Clemente XIII.
